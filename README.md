# Abdul Aziz Habib Cleaning Service — Website Samples

Static website samples for **Abdul Aziz Habib Cleaning Service** (Ras Al Khaimah / Dubai, UAE).
Open **`index.html`** at the root to choose a design and preview the live pages.

## Contents

| Path | Design |
|---|---|
| `index.html` | Sample picker — links to both designs below |
| `sample 1/` | **Cyan Clean** — original 5-page concept (deep-navy + cyan, Inter, GSAP). Pages: Home, About, Services, Gallery, Contact |
| `sample 2/` | **Deep Orange** — full 15-page production site (deep-navy + deep-orange, Clash Display + Satoshi). Pages: Home, About, Services (60+ filterable), 7 service pages, Projects, FAQ, Contact, Booking, 404. Includes before/after sliders, B&W→colour equipment-brand ticker, animated loader, FAQ accordions, JSON-LD / Open Graph SEO, `sitemap.xml`, `robots.txt`, `.nojekyll` |

## Tech

Plain HTML + CSS + vanilla JS, Tailwind (Play CDN), GSAP + ScrollTrigger. No build step — everything is static and works from any web server or GitHub Pages.

## Running locally

```bash
# from the repo root
python -m http.server 8000
# then open http://localhost:8000/
```

## Image notes

Some imagery in `sample 2/` is photorealistic AI photography (Gemini "Nano Banana Pro") plus free Unsplash placeholders (Unsplash License — see `sample 2/assets/CREDITS.txt`), pending the final brand photo shoot. Image slots not yet delivered fall back gracefully to topical placeholders.
